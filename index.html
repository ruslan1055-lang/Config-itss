Как использовать:
  1. Заполни поля выше: владелец, репозиторий, токен
  2. Нажми «Загрузить файл с GitHub»
  3. Измени нужные значения в полях ниже
  4. Нажми «Сохранить изменения на GitHub» — файл обновится автоматически

Зелёная рамка = значение изменено от оригинала
